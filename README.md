# Marketing Inventory

Solution of two exercises about a marketing inventory system: the items a company's marketing team buys or rents for its events, where they are, and how much each event costs.

I prepared a README for each exercise.

### Exercise 1: database schema

In **[es1/README.md](es1/README.md)** you will find:

- The database schema designed with dbdiagram.io;
- An overview of the design, assumptions and an example data flow;
- Answers to the exercise questions;
- A description of the tables and their columns.

### Exercise 2: Laravel implementation

In **[es2/README.md](es2/README.md)** you will find:

- A Laravel project with MarketingInventoryService to calculate event cost and item availability;
- A feature test written in Pest to test the service methods;
- Notes and assumptions;
- Instructions to set up the Laravel project and run the feature test.
